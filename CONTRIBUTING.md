# Contributing

Thanks for contributing to **raspberry-pi-chromium-kiosk**.

## Ground rules

- Be respectful and constructive.
- Prefer small, focused pull requests.

## How to contribute

- For the full contribution guide on the web page, go to [First Steps](https://daniel-gia.github.io/raspberry-pi-chromium-kiosk/contribute/first-steps/)
- To see how to setup the development environment and start working on the project see [Setup Environment](https://daniel-gia.github.io/raspberry-pi-chromium-kiosk/contribute/setup-environment/)
- To see how to test your changes locally on your pi see [Test Locally](https://daniel-gia.github.io/raspberry-pi-chromium-kiosk/contribute/test-locally/)


## What to edit (common areas)

- Admin panel (Next.js):
  - `admin-panel/`
- Kiosk runtime scripts/services:
  - `kiosk-browser/start_browser.sh`
  - `kiosk-browser/setup.sh`
  - `kiosk-browser/kiosk-browser.service`
- Setup automation:
  - `setup/setup.sh`
  - `setup/generate-admin-login.sh`
- Docs (MkDocs):
  - `mkdocs.yml`
  - `docs/`
